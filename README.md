# 中药学习宝典

## 简介
一个纯前端单文件中药学习工具，包含中药速记、经典经方、配伍禁忌三大模块，支持统一搜索和卡片翻转背诵。无需安装任何依赖，双击 HTML 文件即可在浏览器中运行。

## 文件说明
- `中药学习宝典.html` — 主程序文件（单文件，包含全部代码与数据）

## 使用方法
1. 双击 `中药学习宝典.html`，用浏览器打开（推荐 Chrome / Edge / Safari）
2. 底部导航切换：中药 / 经方 / 禁忌 / 我的
3. 顶部搜索框支持药名、方名、功效关键词搜索，支持拼音首字母（如输入 bz 可搜索白芷）
4. 点击"开始背诵"进入卡片翻转模式，支持左右滑动、点击翻转、随机顺序
5. 学习进度、收藏、设置自动保存在浏览器本地（localStorage）

## 数据内容
- 中药：305味，按19个功效大类（41个细化功效）分类，每味含性味、归经、功效、用量、速记关键词、配伍禁忌（其中139味标注"沈常用"）
- 经方：20首经典方剂，含组成剂量、功用、主治、原文出处
- 禁忌：十八反（歌诀+3组对照+临床要点）、十九畏（歌诀+10组）、妊娠禁忌（禁用28味+慎用43味）

## 注意事项
- 本工具仅供学习参考，临床用药请遵执业中医师辨证指导
- 学习数据保存在当前浏览器，清除浏览器数据会丢失进度
- 建议使用现代浏览器，分辨率 375px 以上效果最佳
