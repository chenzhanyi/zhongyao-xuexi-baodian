# 针灸穴位库（本地化存档）

采集自 **手机中医中药网**（m.zhzyw.com）《针灸穴位大全》专题页 `https://m.zhzyw.com/zt/xwdq/`，
按 **十四经**（十二正经 + 督脉 + 任脉）整理，共 **358 个穴位**，已做本地化存档，不依赖原站文字内容。

## 目录结构

| 文件 | 说明 |
|---|---|
| `xuewei.js` | 穴位数据：`const XUEWEI = [ {n:穴名,m:经脉,py:拼音,src:出处,img:体表图,cap:图注,dw:定位,jp:解剖,zz:主治,cz:操作,pw:配伍,bz:附注}, … ]`（358 条） |
| `img/` | 各穴体表定位图（gif，本地化，`xuewei.js` 以 `xuewei/img/xxx.gif` 引用） |
| `scrape_xuewei.py` | 采集脚本（GBK 解析、十四经分组、内页字段抽取、电话清理、图片本地化） |
| `xuewei_list.html`、`xuewei_raw.json` | 列表页 / 内页原始缓存（可断点续抓，不入库） |

## 数据字段

| 键 | 含义 |
|---|---|
| `n` | 穴名 |
| `m` | 所属经脉（手太阴肺经…足厥阴肝经、督脉、任脉） |
| `py` | 拼音 |
| `src` | 出处（如《灵枢·本输》） |
| `img` | 体表图（本地 gif 路径） |
| `cap` | 图注（如"尺泽-体表图"） |
| `dw` | 定位 |
| `jp` | 解剖 |
| `zz` | 主治 |
| `cz` | 操作（刺灸法） |
| `pw` | 配伍 |
| `bz` | 附注（特定穴属性等） |

## 重新采集

```bash
python3 scrape_xuewei.py            # 仅解析列表 + 试抓 3 条
python3 scrape_xuewei.py --apply    # 全量抓取并重新生成 xuewei.js（走本机代理）
```
